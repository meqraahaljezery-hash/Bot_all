## 🌟 نظرة عامة على المشروع

تم بناء هذا المشروع ليكون نظاماً متكاملاً مستقلاً يخدم طلاب ومعلمي ومشرفي **مقرأة الإمام الجزري**. يشمل المشروع:
1. **بوت تيليجرام حقيقي ومستقل** مبني بلغة Python 3.12 وإطار عمل `aiogram 3.x` مع دعم كامل لنمطي Polling و Webhook.
2. **لوحة تحكم ويب تفاعلية كاملة** مبنية بـ React و TypeScript وتنسيقات Tailwind CSS بهوية إسلامية هادئة (اللون الأساسي: `#105C3B`).
3. **محاكي حي للبوت** داخل لوحة الويب لاختبار تجربة المستخدم مباشرة من المتصفح.
4. **دفتر حسابات مالي ذري (Atomic Financial Ledger)** يضمن عدم تكرار إضافة الدقائق أو اعتماد المعاملات مرتين عبر مفاتيح عدم التكرار (`idempotency_key`).
5. **نظام صلاحيات مركزي (RBAC)** دقيق يفصل بين صلاحيات المدير العام، المشرف، المعلم، والطالب.
6. **دعم كامل لـ 3 لغات**: العربية (اللغة الافتراضية)، الإنجليزية، والأمهرية.

## 🚀 المميزات والوظائف الأساسية

- 📖 **التعريف بالمقرأة**: رسائل ترحيبية وتوضيح لرؤية المقرأة وأهدافها.
- 📚 **البرامج التعليمية الديناميكية**:
  1. التلقين وتصحيح الأداء.
  2. الحفظ المكثف.
  3. الإجازة برواية حفص عن عاصم.
  4. الإجازة بالقراءات السبع.
- 📝 **نظام تسجيل متعدد الخطوات (FSM)**: جمع بيانات الطالب (الاسم، العمر، الجنس، الدولة، المدينة، الهاتف، المستوى، الرواية، الأوقات المناسبة، وملاحظات ولي الأمر)، مع شاشة مراجعة نهائية وإمكانية التعديل قبل الإرسال.
- 💳 **باقات الدقائق المعتمدة**:
  - 100 دقيقة = 500 ETB
  - 200 دقيقة = 1000 ETB
  - 300 دقيقة = 1470 ETB
  - 400 دقيقة = 1920 ETB
  - 500 دقيقة = 2350 ETB
  - 600 دقيقة = 2760 ETB
  - 1000 دقيقة = 4500 ETB
- 🏦 **طرق الدفع اليدوي المحمية**: دعم (CBE, BOA, Telebirr, M-Pesa) مع إرفاق الإيصال والمرجع البنكي وتاريخ التحويل.
- 🔒 **الحماية المالية الصارمة**: لا تضاف الدقائق عند تقديم الطلب؛ تُعتمد العمليات يدوياً من الإدارة عبر معاملة ذرية تحفظ الرصيد قبل وبعد العملية والمسؤول المعتمد.
- ⏱ **سجل الدقائق والرصيد**: عرض الرصيد المتاح، المشتريات، المستهلكات، والمكافآت مع سجل تفصيلي لكل حركة.
- 👥 **حلقات ومجموعات قرآنية خاصة**: الطالب يرى حلقته ورابط التيليجرام الخاص بها فقط دون إمكانية رؤية باقي الحلقات، والمعلم يرى طلابه وحلقاته فقط.
- 💬 **نظام تذاكر الدعم الفني**: فتح تذاكر برقم تسلسلي فريد ومحادثة مباشرة مع المشرفين.
- 📢 **إعلانات ورسائل جماعية**: إرسال تدريجي يحترم قيود التيليجرام وفلترة حسب البرنامج أو الحلقة.

## 🛠 التقنيات المستخدمة

- **الواجهة الخلفية والبوت**: Python 3.12, aiogram 3.17+, FastAPI, Uvicorn, Pydantic 2.
- **قواعد البيانات**: PostgreSQL 16 / Supabase PostgreSQL, asyncpg, SQLAlchemy 2.0.
- **لوحة التحكم الويب**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Vite.
- **التخزين المؤقت**: Redis 7 (اختياري للحالات والطوابير).
- **الحاويات والأتمتة**: Docker, Docker Compose, GitHub Actions CI.
- **الاختبارات**: Python unittest & Pytest (26 اختبار تغطي كافة المتطلبات).

## 🤖 طريقة إنشاء بوت تيليجرام عبر BotFather

1. افتح تطبيق تيليجرام وابحث عن الحساب الرسمي: `@BotFather`.
2. أرسل الأمر: `/newbot`.
3. أدخل اسماً للبوت، مثلاً: `مقرأة الإمام الجزري للإقراء`.
4. أدخل معرّفاً للبوت ينتهي بكلمة `bot`، مثلاً: `AlJazariQuranBot`.
5. سيعطيك BotFather رمز الوصول (Bot Token)، شكله يشبه:
   `7123456789:AAHqweRTYuIop-1234567890abcdefg`
6. احتفظ بهذا الرمز وضعه في ملف `.env` تحت المتغير: `BOT_TOKEN`.
7. لضبط أوامر البوت، أرسل لـ BotFather الأمر `/setcommands` وألصق الأوامر التالية:
   ```text
   start - بدء استخدام البوت واختيار اللغة
   help - المساعدة والتعليمات
   language - تغيير اللغة (العربية / English / አማርኛ)
   programs - البرامج التعليمية المتاحة
   register - التسجيل والالتحاق بالمقرأة
   packages - باقات الدقائق والأسعار
   balance - رصيدي من الدقائق وسجل الحركات
   payments - متابعة طلبات الدفع السابقة
   mygroup - حلقتي القرآنية ورابط التيليجرام
   support - الدعم الفني والتواصل مع المقرأة
   cancel - إلغاء العملية الحالية والعودة للقائمة
   admin - لوحة الإدارة للمخولين
   ```

## 🗄 إعداد قاعدة البيانات وسوبابيز (Supabase)

1. ادخل إلى لوحة تحكم مشروع Supabase الخاص بك.
2. افتح قسم **SQL Editor**.
3. قم بتشغيل محتوى الملف `bot/database/schema.sql` لإنشاء الجداول والفهارس بأمان دون مساس بأي بيانات سابقة.
4. قم بتشغيل محتوى الملف `bot/database/seed.sql` لإدخال البرامج الأربعة، الباقات الرسمية، وأدوار النظام.
5. قم بتشغيل محتوى الملف `bot/database/rls_policies.sql` لتفعيل سياسات الأمان والحماية التامة.

> **ملاحظة أمان هامة:** الحسابات البنكية (CBE, BOA, Telebirr, M-Pesa) تأتي غير مفعّلة افتراضياً وبأرقام فارغة (`is_active = FALSE`). يجب على المدير العام الدخول إلى لوحة الإدارة وإدخال الأرقام الحقيقية وتفعيلها.

## 💻 طريقة التشغيل

### أولاً: التشغيل المحلي المباشر عبر Python:
```bash
# إنشاء بيئة وهمية وتفعيلها
python3 -m venv venv
source venv/bin/activate  # في ويندوز: venv\Scripts\activate

# تثبيت المكتبات
pip install -r requirements.txt

# تشغيل البوت
python -m bot.main
```

### ثانياً: التشغيل بواسطة Docker Compose:
```bash
docker-compose up --build -d
```
لعرض السجلات التشغيلية:
```bash
docker-compose logs -f bot
```
